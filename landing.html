سوالات متداول

شاید این سؤالات رو داشته باشی.

آیا برای استفاده از قالب، به دانش برنامه‌نویسی نیاز دارم؟

برای استفاده‌ی ساده و اجرای قالب، فقط کافیه فایل‌ها رو در هاست خودت آپلود کنی. برای شخصی‌سازی، آشنایی پایه با HTML و CSS کافیه. مستندات کامل هم همراهش هست.

چطور می‌تونم قالب رو ویرایش یا سفارشی کنم؟

همه‌ی رنگ‌ها و متغیرهای طراحی در فایل input.css به‌صورت متغیر CSS تعریف شدن. با تغییر چند خط، می‌تونی رنگ‌های برند خودت رو اعمال کنی. برای تغییرات بیشتر، فایل‌های HTML ساده و بدون فشرده‌سازی هستن.

آیا پشتیبانی و آپدیت داره؟

بله. پلن Basic بدون پشتیبانی، پلن Pro با ۶ ماه پشتیبانی و ۱ سال آپدیت رایگان، و پلن Enterprise با ۱ سال پشتیبانی اختصاصی ارائه می‌شه.

امکان بازگشت وجه وجود داره؟

بله. تا ۷ روز پس از خرید، اگر از قالب راضی نبودی، با تماس با پشتیبانی، مبلغ کامل بهت برگردونده می‌شه — بدون سؤال.

قالب با چه مرورگرهایی سازگاره؟

با همه‌ی مرورگرهای مدرن: Chrome، Firefox، Safari، Edge و حتی مرورگرهای موبایل. از Tailwind CSS v4 استفاده شده که سازگاری بالایی داره.

آیا فایل‌های Figma هم داره؟

در پلن Enterprise، فایل Figma طراحی هم ارائه می‌شه. برای پلن‌های Basic و Pro، فایل‌های HTML به‌عنوان مرجع اصلی طراحی هستن.

می‌تونم روی چند پروژه استفاده کنم؟

در پلن‌های Basic و Pro، هر لایسنس برای یک پروژه‌ی نهایی معتبره. برای استفاده در چند پروژه، پلن Enterprise (لایسنس چندپروژه‌ای) تهیه کن.

چطور قالب رو دریافت می‌کنم؟

بلافاصله پس از پرداخت موفق، لینک دانلود در ایمیل و پنل کاربری شما نمایش داده می‌شه. اگر به هر دلیلی لینک دریافت نکردی، با پشتیبانی تماس بگیر.

آماده‌ی شروع؟

همین امروز فروشگاهت رو راه بیانداز.

با پلن Pro، همه‌ی چیزی که برای یک فروشگاه حرفه‌ای نیاز داری رو داری — با ۳۰٪ تخفیف رونمایی.
